This mod is the core mod of [Elysium Days](https://modrinth.com/modpack/elysium-days) modpack for fixing issues with mods, adding compatibility, and more.

Support requests outside the Elysium Days modpack will not be considered.

Most features can be toggled in the config using [Fzzy Config](https://modrinth.com/mod/fzzy-config).

<summary>List of Changes</summary>

### Features & Aesthetics

- Adds the Elysium Days Logo on the Main Menu and the Taskbar Icon
- Adds a Discord Button on the main menu
- Adds a Wiki Button on the main menu
- Adds a RAM Warning Screen
- Adds a New Panorama
- Adds prettier banners for [Modern World Creation](https://modrinth.com/mod/modern-world-creation)

### Compatibility & Fixes

- Adds [EMI](https://modrinth.com/mod/emi) configurations for tweaks
- Adds custom Eye of Ender warning translations for [End Remastered](https://modrinth.com/mod/endrem) mod to ensure compatibility with [The Lost Castle](https://modrinth.com/mod/the-lost-castle)
- Adds 2 Loot Tables for [End Remastered](https://modrinth.com/mod/endrem) eyes for injection with [Datapatched](https://modrinth.com/mod/datapatched)
- Adds [Ender Dragon Revamp](https://www.curseforge.com/minecraft/texture-packs/ender-dragon-revamp) compatibility for [Grindy Elytras](https://modrinth.com/mod/grindy-elytras) fragment texture
- Adds a warning message for [Dimensional Tears](https://modrinth.com/mod/dimensional-tears)
- Adds compatibility for [Vanilla Backport](https://modrinth.com/mod/vanillabackport)'s swimming horses feature with Skeleton Horses and [Eternal Nether](https://modrinth.com/mod/eternal-nether)
- Adds compatibility between [Rustic Delight](https://modrinth.com/mod/rustic-delight) and [More Delight](https://modrinth.com/mod/more-delight)
- Adds compatibility between [Sortilege](https://modrinth.com/mod/sortilege) and [You're in Grave Danger](https://modrinth.com/mod/yigd)
- Adds 1 secret tip for the [Tips](https://modrinth.com/mod/tips) mod
- Adds a feature where your cape gets hidden if you're wearing an [Inmis](https://modrinth.com/mod/inmis) with [Trinkets](https://modrinth.com/mod/trinkets)
- Fixes [Superb Steeds](https://modrinth.com/mod/superb-steeds)'s issue [#9](https://github.com/MoriyaShiine/superb-steeds/issues/9)
- Fixes [Snow! Real Magic!](https://modrinth.com/mod/snow-real-magic)'s issues with some of their block tags
- Fixes [Snow Pig](https://modrinth.com/mod/snowpig-fabric) compatibility with [Fresh Animations: Details](https://modrinth.com/resourcepack/fresh-animations-details)
- Fixes [Ender Dragon Revamp](https://www.curseforge.com/minecraft/texture-packs/ender-dragon-revamp)'s inconsistencies with textures
- Fixes [Particle Interactions](https://modrinth.com/mod/particle-interactions)' Z-Fighting Fix throwing a `ConcurrentModificationException` when particles tick async
- Fixes [InmisAddon](https://modrinth.com/mod/inmisaddon)'s issue [#20](https://github.com/Globox1997/InmisAddon/issues/20)
- Fixes a JEM issue with the Wither Skull when both [Better Mob Models](https://modrinth.com/resourcepack/better-mob-models) and [Darkest Ages Mobs + Fresh Animations](https://www.curseforge.com/minecraft/texture-packs/darkest-ages-mobs-fresh-animations/files/all?page=1&pageSize=20&showAlphaFiles=hide) is used
- Rebalances [Eternal Nether](https://modrinth.com/mod/eternal-nether)'s Wither Skeleton Horses to work better with [Superb Steeds](https://modrinth.com/mod/superb-steeds)

</details>
